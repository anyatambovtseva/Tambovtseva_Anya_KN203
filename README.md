# Тамбовцева Аня КН-203, 8ая задача из файла tasks.pdf
Использование API. Требуется, используя, API В Контакте (или Facebook, yandex) получить информацию и вывести ее в удобочитаемом виде.

Что делает код?

Получает данные из VK API:

Информацию о пользователе (имя, фамилия, пол, дата рождения, город).

Список друзей пользователя.

Список фотоальбомов пользователя.

Выводит данные в консоль в удобном формате.

Поддерживает фильтрацию (например, можно указать, сколько друзей или альбомов вывести).
